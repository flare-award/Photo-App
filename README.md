# Serendip — случайный фотодневник для Android

Serendip сам выбирает несколько случайных моментов в течение дня и делает снимок
основной (задней) камерой, пока вы заняты своими делами. Получается честный,
неотрепетированный дневник дня. Все фотографии остаются только на устройстве.

> Serendip is a random photo diary: a few times a day, at random moments, the app
> takes a photo with the rear camera. Everything stays on the device. The UI is
> Russian-first with a full English translation.

## Что умеет

| | |
|---|---|
| **Автоматические фотографии** | один большой переключатель; режим включается только осознанно, после онбординга с явным подтверждением |
| **Фотографий в день** | 1 · 2 · 3 · 5 · 10 · 20 (и любое значение 1–20 слайдером); счётчик обнуляется в полночь по местному времени |
| **Два режима расписания** | «Полностью случайно» — N моментов распределяются по дню без серий; «Случайный интервал» — после каждой попытки новая случайная пауза в пределах min…max |
| **Не фотографировать при выключенном экране** | опция (по умолчанию выкл.); пропуск не считается снимком и не вызывает «догоняющих» кадров |
| **Уведомление после успешного снимка** | опция (по умолчанию вкл.); только после реально сохранённого и проверенного файла |
| **Главная** | статус, «Сегодня X / Y», «Следующее фото в HH:mm · через N мин», режим, интервал, состояние камеры / уведомлений / фоновой работы / службы, последняя фотография |
| **Фотографии** | сетка миниатюр по дням, полноэкранный просмотр с зумом, «Поделиться», «Удалить» |
| **История** | все попытки: успех, ошибка (человеческим языком), пропуск из-за экрана, пропущенные моменты |
| **Настройки** | авто-фото, уведомления, фоновая работа (статус батареи + переход в системные настройки), разрешения, о приложении |
| **Тёмная тема** | единственная; светлой темы и переключателя нет намеренно |

Чего приложение **не** делает: не включает микрофон, не играет собственный звук
затвора (и не пытается обойти обязательный региональный), не отправляет ничего в
сеть, не запрашивает лишних разрешений (только камера и уведомления), не хранит
ничего сверх настроек, состояния планировщика и истории.

## Сборка и установка

Требования: **Android Studio Quail (2026.1.4) или новее** с её встроенным
JBR 25, Android SDK Platform **37** (compileSdk) и Build Tools 36.0.0 — Studio
скачает недостающее при первом открытии проекта. Телефон с Android **10+**
(minSdk 29) и задней камерой.

```bash
git clone https://github.com/flare-award/Photo-App.git
cd Photo-App
./gradlew :app:assembleDebug          # APK: app/build/outputs/apk/debug/app-debug.apk
./gradlew :app:installDebug           # установить на подключённый телефон
./gradlew :app:testDebugUnitTest      # unit-тесты планировщика (чистый Kotlin)
./gradlew :app:assembleRelease        # release с R8 (нужна своя подпись)
```

Из Studio: *Open* → выбрать папку → *Run ▶*. Debug-сборка ставится рядом с
release как `com.flareaward.serendip.debug`.

Стек: Kotlin 2.4 · AGP 9.3 (встроенный Kotlin, без `kotlin-android`) · Gradle 9.7 ·
Jetpack Compose (BOM 2026.09, Material 3 1.4) · CameraX 1.6 · Room 2.8 (KSP) ·
DataStore 1.2 · Navigation Compose 2.10 · Coil 3 · Coroutines/Flow.

## Первый запуск — что увидит пользователь

1. **Онбординг**: что такое Serendip, как работает фоновая служба, галочка
   «Я понимаю, что приложение будет самостоятельно делать фотографии…».
2. **Камера** — единственное обязательное разрешение. Отказ не ломает приложение:
   показывается статус, кнопка повторного запроса и переход в системные настройки.
3. **Уведомления** (Android 13+) — объясняется, зачем: постоянная карточка службы
   и сообщения о новых фото.
4. **Фоновая работа** — отдельный экран со статусом
   «✅ Работа без ограничений» / «⚠️ Android может ограничивать фоновую работу» /
   «⛔ Фоновая работа ограничена» и кнопкой, открывающей системный диалог
   отключения оптимизации батареи. Это не гарантия съёмки, и приложение так и пишет.
5. **Готово** — включить сейчас или позже с главного экрана.

## Честно про ограничения Android

Эти факты определяют архитектуру и явно описаны в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md):

* **Камера в фоне без foreground service невозможна** (Android 11+). Поэтому пока
  режим включён, работает foreground service типа `camera` с постоянным
  уведомлением.
* **Android 12+ запрещает запускать foreground service из фона**, а
  **Android 14+ дополнительно требует для типа `camera` состояния «while-in-use»**:
  такой сервис можно запустить, только пока активити приложения видна, либо по
  нажатию пользователя на действие в уведомлении. Serendip запускает службу
  **только** из открытого приложения (`MainActivity`) или из кнопки
  «Возобновить» в уведомлении — никогда из будильника или `BOOT_COMPLETED`.
* **После перезагрузки или обновления** служба камеры не запускается
  автоматически (из `BOOT_COMPLETED`/`MY_PACKAGE_REPLACED` это запрещено).
  Приложение восстанавливает настройки, счётчик дня и расписание, ставит
  планировщик на паузу с причиной и показывает уведомление «Возобновить».
  Открытие приложения тоже возобновляет съёмку автоматически.
* **Выключенный телефон не фотографирует.** Пропущенные моменты никогда не
  «догоняются» серией: при следующей возможности расписание просто
  пересчитывается естественно.
* **Doze / оптимизация батареи** может сдвигать пробуждения на минуты.
  Приложение использует `setAndAllowWhileIdle` + оконный будильник плюс таймер
  внутри процесса; режим «Без ограничений» уменьшает задержки, но решение всегда за системой.
* **Производители** (Xiaomi, Huawei, Samsung, OnePlus…) добавляют свои
  ограничители автозапуска. Их нельзя опросить программно; приложение
  показывает общий статус по официальным API и подсказку, где искать настройки.
* `SecurityException` / `ForegroundServiceStartNotAllowedException` **никогда не
  обходятся**: они перехватываются, пишутся в технический лог, а пользователю
  показывается понятный текст и кнопка «Возобновить».

## Структура проекта

```
app/src/main/kotlin/com/flareaward/serendip/
├── domain/        модель данных, интерфейсы репозиториев, CaptureScheduler (чистый Kotlin, тесты)
├── data/          DataStore (настройки, состояние планировщика), Room (история)
├── camera/        CameraXCaptureSource — одиночный снимок задней камерой в MediaStore
├── storage/       MediaStorePhotoStorage — постоянное хранилище Pictures/Serendip
├── scheduler/     AutoCaptureEngine (единая точка решений), будильники
├── service/       AutoCaptureService (FGS camera), ServiceController, receivers
├── notifications/ каналы и уведомления
├── system/        разрешения, батарея, экран, wake lock, лог
├── di/            AppGraph — ручной граф зависимостей
└── presentation/  Compose: onboarding, dashboard, photos, history, settings, theme
```

Подробности — в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Конфиденциальность

Фотографии сохраняются в системную галерею (`Pictures/Serendip`) и принадлежат
пользователю. Приложение не имеет разрешения на интернет, не собирает аналитику,
не анализирует содержимое снимков, не делает резервных копий своих данных
(`allowBackup=false`).
